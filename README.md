# 💰 Pricing Component with Toggle - React Project

An interactive pricing component built with React that allows users to switch between monthly and yearly pricing plans using a toggle switch.

This project is based on a Frontend Mentor challenge and focuses on UI interaction and state management.

---

👉 https://abdessamadachaha.github.io/Pricing-component-with-toggle

---


## 🛠️ Built With
- ⚛️ React
- ⚡ Vite
- 🎨 CSS

---

## ✨ Features
- Toggle between monthly and yearly pricing
- Interactive UI with smooth switching
- Responsive design
- Clean and reusable components

---

## 📚 What I Learned
- Managing state with React (`useState`)
- Implementing toggle logic (ON/OFF switch)
- Conditional rendering in React
- Building UI from design (Frontend Mentor challenge)

---

## 🔁 Toggle Functionality

The main feature of this project is the pricing toggle:

- Monthly pricing 💵
- Yearly pricing 📆

Switching between them updates all pricing cards dynamically using React state.
